# D-L-mode
# 🌙 Dark & Light Mode Toggle

A simple and interactive Dark / Light Mode web application built using HTML, CSS, and JavaScript. It allows users to switch between dark and light themes with a single click.

## 📌 About the Project

This project demonstrates a theme-switching feature that improves user experience by providing two different display modes.

Users can easily switch between Dark Mode and Light Mode according to their preference.

## ✨ Features

- 🌙 Dark Mode
- ☀️ Light Mode
- 🔄 One-click theme switching
- 🎨 Smooth theme transitions
- 💻 Clean and modern user interface
- 📱 Responsive design
- 💾 Theme preference saved using Local Storage (if implemented)

## 🛠️ Tech Stack

- **HTML5** – Webpage structure
- **CSS3** – Styling and theme customization
- **JavaScript** – Theme switching functionality
